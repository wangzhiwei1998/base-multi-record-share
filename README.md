# 多条记录分享（多维表格边栏插件）

一次选择多条记录，批量生成记录分享链接，汇总成一段可复制文本，粘贴给飞书中有权限的用户，对方点击链接即可按其多维表格权限查看对应记录。

## 功能

- 读取当前数据表 / 视图，分页加载全部记录；**标题字段可任选**（默认为首字段），列表、搜索与分享文案均使用该字段
- 支持搜索、勾选多条记录，全选 / 清空
- 一键批量生成记录分享链接（`table.getRecordShareLink`），并发执行、显示进度、可取消
- 检测当前视图分享状态，未开启时可一键开启（二次确认）
- 结果支持：复制全部（纯文本）、复制为 Markdown、仅复制链接、逐条复制
- 浅色 / 深色主题自适应，中 / 英 / 日三语
- 实时响应切换表 / 视图、记录增删，无需手动刷新

## 开发

```bash
npm install
npm run dev     # 本地开发（不在多维表格中时进入预览模式，展示示例数据）
npm run build   # 构建产物到 dist/
```

## 使用方式

1. 构建并部署 `dist/` 目录到任意 HTTPS 静态托管（或使用本地开发服务地址）
2. 在多维表格中点击「插件」→「自定义插件」→「+ 新增插件」，填入插件运行地址
3. 在插件中勾选要分享的多条记录，点击「生成分享链接」，复制内容粘贴给有权限的用户即可

> 说明：获得链接的用户以其在多维表格中的既有权限访问记录；若对方无权限，需要先在其可访问范围内开通权限。
